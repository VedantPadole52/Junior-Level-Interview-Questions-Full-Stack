# Junior Full-Stack Interview Questions

A curated collection of common junior-level full-stack developer interview questions and notes. This repo is meant for self-practice and to help other beginners prepare for technical interviews with confidence.

## 📚 Topics Covered

- **HTML & CSS**
- **JavaScript (Basics + Advanced)**
- **React.js**
- **Node.js**
- **Express.js**
- **MongoDB / SQL**
- **REST APIs**
- **Authentication & Security (Basics)**
- **Git & GitHub**
- **Basic System Design Questions**
- **Behavioral/HR Questions**

## ✅ Why This Repo?

- For consistent interview preparation.
- To track my own progress and understanding.
- To help other beginners in the full-stack journey.

Each folder contains:
- Topic-wise questions
- Short explanations or answers
- Code snippets (if applicable)
